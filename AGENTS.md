# Agents

- Never run `hugo` commands locally.
- Put blog posts in `content/posts/` and short stories in `content/stories/`. Do not create new content directories or reorganize structure.
- Put images in `static/img/` and reference them as `/img/filename.ext` (never relative paths).
- New posts default to `draft: true` unless asked to publish.
- Front matter uses only `title`, `date`, and `draft` unless asked otherwise.
- When writing or editing content, read `TONE_OF_VOICE.md` first.
